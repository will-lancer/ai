# ai

Research on AI control, evaluation, and learned behavioral equilibria.

- `research/control/lean-reward-hacking/` contains the Lean proof-interface evaluator and reward-hacking experiments.
- `research/personas/two-equilibria/` studies two hidden-behavior outcomes under one fixed RLHF objective.
- `resources/` documents the local study library. Large datasets, downloaded references, nested repositories, and generated environments stay outside Git.
